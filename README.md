# Игровой симулятор для проводников ВСМ

Решение кейса по геймификации обучения персонала высокоскоростных магистралей. Приложение обучает сотрудников действовать в стрессовых и внештатных ситуациях с использованием механики ограничения времени и динамических KPI.

## Структура проекта
* index.html — интерактивный фронтенд-симулятор (клиентская часть)
* main.py — серверная логика игрового движка (бэкенд на FastAPI)
* сценарии и конфигурационные данные сохранены в загруженных JSON-файлах в корне репозитория

## Инструкция по локальному запуску
1. Склонируйте этот репозиторий или скачайте файлы в одну папку.
2. Откройте файл index.html в любом современном браузере для запуска симулятора.
3. Для запуска бэкенда установите зависимости команды: pip install fastapi uvicorn
4. Запустите сервер командой: uvicorn main:app --reload
